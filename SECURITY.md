# Security reporting

This repository is private and the initial implementation is unaudited. Report suspected vulnerabilities directly to the repository owner through an authorized private channel. Include a minimal reproduction, affected version and whether authority or quota enforcement can be bypassed. Do not include signing keys, production grants or customer data in a report.

Version 0.1 is the only current implementation. No support or patch-response commitment is made yet. See `docs/THREAT_MODEL.md` for trusted components and deployment requirements.
